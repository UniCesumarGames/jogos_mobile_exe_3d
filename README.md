## Para que serve este repositório?

Projeto-base **3D** para exercícios de **jogos mobile**.

Contém o template Unity + `SampleScene`. Ideal para:

- Montar um personagem 3D simples  
- Testar câmera e toque em dispositivo/emulador  
- Evoluir para build Android conforme o roteiro da aula

## Tecnologias

| Item | Detalhe |
|------|---------|
| Engine | Unity (template 3D) |
| Tipo | Exercício / sandbox de aula |

## Estrutura atual

```
Assets/
├── Scenes/SampleScene.unity
└── TutorialInfo/ ...
Packages/
ProjectSettings/
```

## Como abrir (aluno)

1. Clone:
   ```bash
   git clone https://github.com/UniCesumarGames/jogos_mobile_exe_3d.git
   ```
2. Abra no Unity Hub  
3. `SampleScene` → **Play** e comece a implementar o enunciado da semana
